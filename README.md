# Manisha & Neel — Save Our Date

A mobile-first digital wedding invitation built with plain HTML, CSS, and JavaScript.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and folder in this directory, including `assets/`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will provide a public URL for the invitation once deployment completes.

## Local preview

Open `index.html` in a modern web browser.
